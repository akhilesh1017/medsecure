# MedSecure Hospital Database System

MedSecure is a modern secure healthcare management platform designed for hospitals and clinics.  
It provides encrypted patient data management, appointment tracking, medical records, prescriptions, and privacy-focused healthcare security.

## Features

- Military-grade encryption
- Patient dashboard
- Medical records management
- Appointment scheduling
- Lab result tracking
- Prescription management
- Privacy & consent controls
- Responsive modern UI
- Dark mode support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
